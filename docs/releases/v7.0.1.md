青燃 7.0.1：原「青阳」正式更名，继续按自己的节奏训练。

### 本次更新

- 统一 App 桌面名、顶部标题、关于页和下载包名称为「青燃」。
- 修复跨过午夜后切回训练、饮食页仍停在昨天的问题；正在查看的历史日期不会被自动改掉。
- 修复横屏打开键盘时编辑弹窗溢出，空间紧张时可滚动到输入区和保存按钮，保留输入状态。
- 修复大字号下底部导航文字溢出。
- 复核顶部计时药丸动画、快速启停、日期与页面切换、主题、动作全选与取消全选。

### 下载与升级

- 下载 **Qingran-v7.0.1-arm64.apk**，Android 7.0 及以上 ARM64 设备，版本 7.0.1（89）。
- 仍使用原包名 `com.body.recomp` 和正式签名，可覆盖旧正式版，已有记录继续保留。建议升级前导出 JSON 备份。
- 原「青阳 预览」与新的「青燃 预览」仍是独立预览包。迁移到正式版时，先从预览版导出 JSON，再在正式版导入。
- 备份仍使用 schema 3；此次改名不改变存储键、备份识别和旧数据迁移逻辑。
- 附 SHA-256 校验文件。源码标签和旧发布保留。

### 验证范围

Flutter 回归测试、静态分析、界面渲染检查和 GitHub Actions 正式签名构建。未连接实体 Android 手机，本次不包含真机帧率与安装验收。
