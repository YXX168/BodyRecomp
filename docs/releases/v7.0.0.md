青阳 7.0：按自己的节奏训练，用模板参考，用记录看变化。

### 本次更新

- 从固定课表重构为自由组合的训练积木，内置 52 项动作，可搜索、分类、多选、自定义和排序。
- 每周安排作为参考模板；实际训练按日期独立保存，支持补记、部分完成、休息标记和保存模板。
- 饮食日记与体重、围度趋势一起管理，支持 JSON 备份和旧版数据迁移。
- 全新轻量界面、六套主题与马卡龙色图标，统一编辑面板和选择状态。
- 顶部计时药丸仅在计时期间显示，带淡入淡出；快速结束再开始不会叠出两层，切换页面或日期不重置计时。
- 日期入口按需打开日历；不同日期的动作展开状态与滚动位置分别保留。

### 安装与升级

- 下载 **Qingyang-v7.0.0-arm64.apk**，适用于 Android 7.0 及以上的 ARM64 设备。
- 正式包名仍为 `com.body.recomp`，沿用原正式签名，可覆盖旧正式版。升级前建议先导出 JSON 备份。
- 此前的「青阳 预览」是独立应用。请在预览版导出 JSON，再在正式版导入；确认记录完整后再移除预览版。
- 新版备份为 schema 3，可读取旧 schema 1 / 2；旧版无法读取新版备份。
- 计时依据真实截止时间校准；不提供后台通知，退出应用进程后不恢复计时。

附件提供 APK 与 SHA-256 校验文件。正式构建会核验包名、版本和原签名证书；本轮完成自动交互与布局检查，尚未在实体安卓设备上验证流畅度。
