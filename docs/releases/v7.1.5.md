青燃 7.1.5 彻底重构了左右滑动切换日期与顶部周历联动体验：改用原生 `PageView` 1:1 双页并行跟手翻页与临界阻尼丝滑弹簧物理，让顶部周历胶囊实时追踪滑动进度并在跨周时平滑流转，同时训练总览卡片随顶部日期条自然同滑隐藏，消除此前切换时的闪跳与急促感。

### 本次更新

- **原生 1:1 跟手切日翻页（`DayPageView`）**：以支持跨天并行渲染的原生 `PageView.builder` 与 120Hz 临界阻尼弹簧物理（`mass: 1.0, stiffness: 145.0, damping: 24.4`）取代单页瞬时替换，松手后自然优雅滑入；彻底解决旧版单页偏移叠加半透明闪跳与动画过快生硬的问题；饮食页同步升级至 `DayPageView`。
- **顶部周历胶囊实时追踪与文字渐亮**：`WeekStripBar` 通过 `pageProgress` 实时对齐当前翻页分数，文字与日期数字随液态胶囊经过平滑点亮，跨周翻页（周日 ↔ 周一）时胶囊顺滑滑出边缘并从新周另一侧流转进入；点按周历及 `<`/`>` 按钮同步采用 340–528ms 柔和缓动曲线。
- **总览卡片与顶部周历同滑隐藏**：取消原先吸顶固定与裁剪层割裂感，每条训练日维护独立滚动位置，下滑列表时周历条与总览卡片 1:1 共同平滑收起；从已下滑天横滑至未下滑天时，顶部周历条随之顺滑下滑显露，全程零跳变、零遮挡透视。
