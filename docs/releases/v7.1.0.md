青燃 7.1.0 带来全新流光液态玻璃界面重构、每日固定训练模板与可自由增删的个人动作库。

### 本次更新

- **全新流光液态玻璃界面与 4 标签极简架构**：精简为「训练 / 模板 / 动作库 / 我的」四大主标签；配备 6 套高通透极光明暗主题、缓存式极光背景与无弹跳液态水滴滑动底部胶囊（支持点击滑移与直接左右拖动切换）。
- **每日固定训练模板**：周一至周日均自动载入对应固定模板，支持内联可视化模板工作室调整每日课表、排序及增删模板动作；未打卡前不提前写入历史，编辑模板不影响历史记录。
- **个人动作库增删改查**：双列流光卡片视图，支持搜索、分类筛选、收藏、新建自定义动作、编辑、删除撤销、一键加入今日训练及恢复内置动作（保留自建）。
- **训练体验细节打磨**：顶部周历条采用扁平紧凑设计，浏览列表时下滑自动隐藏、上滑立即出现，总体训练概览卡片自动锁定吸顶显示实时进度与全新极简肌群剪影；默认体重调整为 69kg，历史数据损坏时保留原数据导出恢复通道。

### 安装与升级

- 安装包为 **Qingran-v7.1.0-arm64.apk**，适用于 Android 7.0 及以上 ARM64 设备。版本号为 7.1.0，内部构建号为 91。
- 沿用原正式版包名（`com.body.recomp`）与官方正式签名，可直接覆盖升级并完整保留已有训练、体重、饮食与主题记录。发布附件中附有 SHA-256 校验文件。
- 如曾在预览版记录过新数据，可在预览版「我的 → 数据备份」导出 JSON，再在正式版导入合并。
