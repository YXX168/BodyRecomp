青燃 7.0.2 改善了动作搜索、日期切换和记录操作。

### 本次更新

- 横屏打开键盘时，动作选择面板可以滚动查看搜索结果，确认按钮保持可用。
- 训练和饮食页的日期栏固定在顶部，滚动记录时也能切换日期。
- 停留在当天视图跨过午夜后会自动切到新的一天。手动查看的历史日期会保留，已经打开的训练项目菜单仍操作原项目。
- 优化日期控件和饮食卡片的按压反馈，底部导航与动作分类遵循系统的减少动画设置。

### 安装与升级

- 安装包为 **Qingran-v7.0.2-arm64.apk**，适用于 Android 7.0 及以上 ARM64 设备。版本号为 7.0.2，内部构建号为 90。
- 沿用原正式版包名和签名，可以覆盖升级并保留已有记录。发布附件中附有 SHA-256 校验文件。
- 如用预览版记录了数据，可在预览版导出 JSON，再在正式版导入。
